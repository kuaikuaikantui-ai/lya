## 一、danbo（蛋播）架构与功能图谱

**技术栈**：Flutter + `media_kit`（mpv 内核播放器）+ FFmpeg/`Dav1d`（AV1 软解）+ `flutter_inappwebview`（混合网页）+ `sqflite`/`hive`（本地库）+ Supabase 自建后端（`38.76.202.248:8000`，auth/rest/storage/realtime）。

**已确认功能清单**（自二进制字符串提取）：

| 模块 | 功能点 | 对 Lya 的借鉴价值 |
|---|---|---|
| 播放器 | mpv 内核、长按倍速零卡顿、清晰度信息、DLNA 投屏 + AirPlay（flutter_to_airplay）、屏幕亮度手势、常亮/睡眠暂停 | ⭐⭐⭐⭐ 长按倍速流畅根因=原生管线；web 层只能靠减少重配+抑制重建逼近 |
| 短剧 | 微短剧频道、短剧推荐流预取、短剧备用解析（失败自动换）、短剧记录/本地备份 | ⭐⭐⭐⭐⭐ 直接对应我们的 kanju 短剧源与上下滑流 |
| 影视推荐 | **豆瓣 API 深度集成**：`movie.douban.com/j/search_subjects`、`/j/subject_suggest`、年度电影榜单、豆瓣高分、豆瓣短评/剧照/演职员；SuperWebView 注入点击拦截脚本捕获豆瓣页面点击 | ⭐⭐⭐⭐⭐ 分类/榜单体系直接参考豆瓣；网页注入思路可用于豆瓣跳转搜索 |
| 数据源 | `cj.lziapi.com`（量子）、`jszyapi.com`（极速）、`bfzyapi.com`（暴风）— 与我们同款 CMS 源；解析线 `jx.wolongzywcdn.com:65/m3u8.php?url=` | 确认我们源池与头部竞品一致；可评估补 wolong 解析线 |
| 音乐 | 网易云/酷我/Joox 搜索与外链、音乐榜单、华语流行热歌 | ⭐⭐ 低优先，暂不做 |
| 听书/TTS | fqnovel 设备注册 + multi_video_model 听书、tts.wangwangit.com 语音合成 | ⭐⭐⭐ 小说 TTS 听书是差异化功能，列入 backlog |
| 书城 | 书源规则解析（类 Legado 规则）、书架排序、下载全书、阅读进度 | ⭐⭐⭐⭐ 规则化书源是长线方向；本轮先做内置源体检 |
| 下载 | M3U8 视频下载队列、下载管理、下载目录；小说章节批量下载 | ⭐⭐⭐⭐ 离线下载为高价值 backlog（浏览器端可用 IndexedDB/OPFS 实现） |
| 社区/发现 | 发现页、片单收藏、观看统计图表（最近观看概览、活动趋势柱形图） | ⭐⭐⭐ 统计图表可简化移植到"我的"页 |
| IPTV | `danboxingqiu.cn/iptv.m3u` 直播源、用户自添加直播源 | ⭐⭐ backlog |
| 会员 | VIP/兑换码/二维码收款人工开通 | 不借鉴（合规风险） |
| 其他 | 扫码（mobile_scanner）、图片选择/裁剪（DKImagePicker）、分享（share_plus）、存相册（gal） | ⭐⭐ 按需 |

**danbo 播放器丝滑的关键启示**：长按倍速不卡 = mpv 原生管线 + 预创建 HUD。我们在 WKWebView 里能做的最优近似：降延迟、去 backdrop-filter 首绘、`preservesPitch` 切换、看门狗抑制、rAF 错峰。

## 二、kanju（源站）可借鉴点

- **多线路配置自发现**：`kanju15-19.com` / `souju1-7.com` / `ksw399.com:9800` / `weilai555.com` 一批镜像配置端点（`/stgo2026/notes/config440.txt` 等），启动时逐个探测取可用配置 → 我们已实现 KANJU_HOSTS，可扩充镜像列表。
- **DoH 解析**：内置 `doh.pub/dns-query` 与 `dns.alidns.com/dns-query` —— 被污染域名走 DoH 解析后直连 IP。Cloudflare Worker 端无 DNS 污染问题，但**客户端直连源**（直连兜底模式）可借鉴。
- **详情数据模型**：`type_name`、`tags[]`、`members[]`（导演/演员分型）、`recommendList[]`（带 `collect_count` 收藏数与 `label` 标签如"最多人看"）→ 我们的详情页与推荐可参考此模型。

## 三、本轮落地 vs backlog

**本轮落地（对应用户需求）**：
1. 频道推荐体系 ← danbo 豆瓣分类体系 + 我们 CMS 源自身分类（需求 2）。
2. 长按倍速丝滑化 ← danbo 手感逼近（需求 1）。
3. 线路切换面板（后端已有 resolve-line 多线能力，前端补面板）。
4. 最近观看/阅读 + 统计入口（需求 2c）。
5. 上下滑短剧/吃瓜流 ← danbo 短剧推荐流预取思路（需求 2b）。

**Backlog（记录待后续迭代）**：M3U8 离线下载、小说 TTS 听书、规则化自定义书源、DLNA 投屏、IPTV、音乐模块、观看统计图表、豆瓣短评/演职员详情页。
