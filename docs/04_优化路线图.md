# Lya 优化路线图（Backlog · 2026-11-21 复查轮整理）

> 依据：danbo（蛋播）二进制串情报（18.5 万条）+ kanju 镜像端点 + 开源项目最佳实践
> （ArtPlayer/xgplayer/hls.js/Mihon/Legado/Mux/Cloudflare 官方模式）。按价值×可行性排序。

## A. 中期（1-2 周内可落地，已有明确实施路径）

### A1. 豆瓣榜单频道（供需侧增强）
- 证据：danbo 用 `/j/search_subjects`（tag=豆瓣高分）、`/j/new_search_subjects`（标签×年份矩阵）、`movie.douban.com/annual/`（年度榜单）；本地实测豆瓣 j API 0.65s 可达。
- 落地：`/api/video/douban-rail?kind=` + KV 缓存 6h + referer + 静默降级；豆瓣条目→标题→CMS 聚合搜索匹配可播卡片。
- 风险：豆瓣反爬（识别"豆瓣安全中心"页后静默降级，danbo 同款）+ 片源命中率。

### A2. 跳过片头/片尾自动化
- 证据：danbo `skipStartEnabled` 状态机 + `片头: /片尾: `标记存储；Lya 已有手动跳片头按钮（+85s）。
- 落地：长按标记"片头到此为止/从此处为片尾"→ 存 /api/sync KV → loadedmetadata 自动 seek；UI 在设置面板。

### A3. 线路测速面板 + 优先线路 pin
- 证据：danbo `播放源健康度保存失败:`（per-source 健康度持久化）、`优先播放源`、`播放源管理`。
- 落地：现有 smartProbeAndSwitchRoute 之上加可视化测速（逐线 resolve + Range 探测 ms 徽标，并发≤3，结果 sessionStorage 缓存），允许 pin 首选线路。

### A4. 短剧上下滑（backlog 项的实施加固清单）
- qingtian 配置已含 6 个短剧源（番茄/YY短剧/星芽短剧/东梨短剧/量子影视/非凡影视）。
- danbo 加固清单：备用解析链逐源降级（带 source 标注）、云记录+本地备份双写且读失败不清数据、Wi-Fi 感知预取（feed.js 已实现）、退出页显式销毁、常亮走 nativeScreenSleep（已实现）。

### A5. Legado-lite 规则书源（首批试点清单已就绪 2026-11-21）
- 证据：danbo 自身即受限 Legado 兼容子集（字段白名单 `bookSourceName/Url/Group`、`ruleContent.replaceRegex`、`contentNextPageMode`）；Dendi213/legado-rule 证明轻量引擎可行。
- 落地（v1 子集）：@css: + @json:($.path) + replaceRegex + URL 模板 + GET-only + **每源域名 allowlist（SSRF 防护）** + 目录分页环上限；JS 块/xpath 明确报"首期不支持"。
- **首批试点源**（取自 XIU2/Yuedu 精选 22 源，已剔除标注"人机验证/梯子/暂不可用"的 13 个，存档 `shuyuan.json`）：速读谷 sudugu.co、得奇 deqixs.com、快书网 kuaishu5.com、手机小说 shoujix.com、铅笔小说 23qb.com、艾途 aitbooks.com、阅友 suixkan.com、就爱 92xs.info、武林中文网 50zw.so（本轮本机探测多数 403/超时=反爬，需规则引擎配合 CF 出口再实测）。
- **danbo（蛋播）书源**：位于其自建 Supabase（38.76.202.248:8000，表 `public.reading_sources`），anon 角色无权限（permission denied），需其用户体系登录后经 edge function 同步——无法直接获取；其架构（云端书源+字段白名单校验+域名 allowlist）已在本路线图中采纳。

### A6. 漫画跨章预读 + img_proxy 增强
- Mihon ReaderPageLoader 模式：当前章读到 70% 预取下一章前 2-3 页（prefetchNextChapter 已有雏形，补"70% 触发"策略）。
- img_proxy 加长 TTL Cache API 缓存 + `Accept: image/webp` 透传协商。

### A7. iOS 壳差异化（纯 native）
- 后台播放：AVAudioSession playback（视频息屏续听）。
- 原生亮度手势：danbo 系统亮度插件模式（screen_brightness 走原生桥）。
- douban SuperWebView 注入桥：壳内开豆瓣年度榜单页 → 注入点击拦截 → "在 Lya 播放"唤起站内搜索（danbo 验证过的 UX）。

## B. 长期探索

- **M3U8 离线下载**：danbo 状态机词表可直接做 i18n 蓝本（`正在加入队列/暂停下载/恢复下载/下载失败,重试/队列已暂停或已完成`）；分片级缺失容忍 + 补下载（`已下载 X%，已保留下载内容，可重试补齐`）；MP4 与 M3U8 双管线。浏览器端用 IndexedDB/OPFS。
- **小说 TTS 听书**：tts.wangwangit.com 是 OpenAI 兼容 speech 端点（danbo 在用）；fqnovel multi_video_model 需设备注册（合规风险高，慎接）。
- **IPTV 直播**：`danboxingqiu.cn/iptv.m3u` + 用户自添加直播源。
- **音乐模块**：meting/qijieya/oiapi 聚合（danbo 在用），低优先。
- **观看统计图表**：danbo 口径 = 每部作品只存 lastWatchTime + 最新续播进度（诚实口径：不推算累计时长），按周期分桶柱状图；隐私开关已落地。
- **解析线补充**：`jx.wolongzywcdn.com:65/m3u8.php?url=`、`dmplay.knowhub.vip/d?url=` 作为 resolve-line 附加候选（失败即弃）。

## 已明确的"不做"

- Supabase 竞品后端（不可控依赖+合规风险）；音量手势（iOS Safari 只读）；CSS multicol 分页重构（iOS 端部裁切坑，现 JS 量测引擎保持）；hls.js 参数调优对 iOS 无效（iOS 无 MSE 走原生 HLS，现有 feature-detect 兜底是唯一正确姿势）。
